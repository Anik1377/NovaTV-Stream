   103→--- [CRITICAL-03] Unauthenticated Supabase Setup Endpoint (DDL) ---
   104→File: /home/z/my-project/src/app/api/supabase/setup/route.ts, Lines 8-37
   105→Severity: CRITICAL
   106→Finding: `POST /api/supabase/setup` has zero authentication. Any unauthenticated user can hit this endpoint. While the current implementation only returns SQL (not executing it via the REST path shown), the endpoint still makes a fetch call to `${supabaseUrl}/rest/v1/rpc/exec_sql` using the PUBLISHABLE_KEY as both `apikey` and `Authorization: Bearer`.
